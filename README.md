## About

Dynamic FPS notices when Minecraft is not the window you are looking at, and stops burning your GPU on frames nobody sees. Alt-tab and the frame rate drops to a trickle; return and it restores instantly. On laptops this is the difference between a fan at full tilt and a quiet machine while you read a wiki.

---

## Features

- Drastically reduces frame rate when the window is unfocused or minimised
- Optional volume reduction or mute while in the background
- Idle detection — throttles even when focused but untouched
- Battery-aware profiles for laptops and handhelds
- Instant restore on refocus with no reload hitch

## Installation

1. **Download** the JAR matching your Minecraft version from the table above.
2. **Install a mod loader** — Forge, Fabric or NeoForge for your exact game version.
3. **Place the `.jar`** into your `.minecraft/mods/` folder (create it if it is missing).
4. **Launch** Minecraft using the modded profile.
5. Verify **Dynamic FPS** appears in the in-game mods list.

> **Tip:** if the game crashes on startup, you almost certainly mixed a Legacy JAR with a Modern
> Minecraft version, or are missing a required dependency. Check `latest.log` first.

## FAQ

**Q: Will it disconnect me from a server?**
A: No — the game keeps ticking and stays connected; only rendering is throttled.

**Q: Can I keep audio playing in the background?**
A: Yes, background volume behaviour is configurable, including leaving it untouched.

**Q: Does it help while actively playing?**
A: Not directly — its benefit is heat, battery and background GPU load.

**Q: Is it safe to add to an existing world?**
A: Yes in most cases — back the save up first, as you should with any mod addition.

**Q: Can I use it in a public modpack?**
A: Yes. Both builds are modpack-ready and require no additional setup.
